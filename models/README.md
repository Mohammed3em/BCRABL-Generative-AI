# Model artifacts

`best_xgboost.pkl` is the compact optimized XGBoost activity surrogate used by the reconstructed reward reference implementation.

The final REINVENT transfer-learning prior and reinforcement-learning agent weights referenced by the TOML configuration files are not included in this publication-oriented GitHub release. Therefore, those configurations document the final scientific settings but require the corresponding historical model weights for end-to-end execution.

Other fitted QSAR model binaries are also excluded because the released prediction tables and independent metric verifier provide the compact reproducibility layer for the reported benchmark.
