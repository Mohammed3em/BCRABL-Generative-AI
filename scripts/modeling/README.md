# Modeling scripts

- `verify_reported_metrics.py` is the release-level validator and can be run from any working directory.
- `study_scripts/` preserves the original model-development code supplied with the project.

The preserved scripts are included for transparency. Several retain the original project-relative directories such as `03_Feature_Engineering`, `04_AI_Models`, and `07_Results`; they are not advertised as a one-command retraining package. See `docs/QSAR_REPRODUCIBILITY.md` for the exact boundary.
