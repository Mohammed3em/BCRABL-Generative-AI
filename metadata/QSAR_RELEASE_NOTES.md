# QSAR release notes — v0.2.0

Added preserved development scripts and evaluation outputs for XGBoost, Random Forest, GIN, ChemBERTa-77M-MLM, and IBM MolFormer-XL. Added optimized tree-model parameters, XGBoost cross-validation results, the five-model benchmark, and an independent metric verifier.

Fitted models and fingerprint matrices are intentionally excluded because they are large derived artifacts. The original Random Forest binaries exceed normal GitHub file limits. No scientific values or prediction rows were altered during packaging.
