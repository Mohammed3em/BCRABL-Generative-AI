# Data Availability Statement

The curated compound-level BCR::ABL1 IC50 dataset, fixed Bemis–Murcko scaffold partitions, data dictionary, validation scripts, file checksums, predictive-model evidence, transfer-learning corpus, target-focused REINVENT4 prior, final reinforcement-learning checkpoint, original custom scoring component, transfer-learning and reinforcement-learning configurations, final 50,000-member pre-docking library, and Supplementary Data S1 are publicly available at [https://github.com/Mohammed3em/BCRABL-Generative-AI](https://github.com/Mohammed3em/BCRABL-Generative-AI). The repository preserves the exact train, validation, and independent-test partitions used in the study and documents the treatment of acyclic molecules as a single scaffold class. ChEMBL- and BindingDB-derived records are redistributed with source attribution under the applicable upstream database terms. Large intermediate working files, nonessential fitted-model binaries, raw docking project files, and molecular-dynamics trajectories are not included.
