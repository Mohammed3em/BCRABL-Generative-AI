# Data Availability Statement

The curated compound-level BCR::ABL1 IC50 dataset, fixed Bemis–Murcko scaffold partitions, data dictionary, validation scripts, file checksums, predictive-model evidence, final 50,000-member pre-docking library, and Supplementary Data S1 are publicly available at [https://github.com/Mohammed3em/BCRABL-Generative-AI](https://github.com/Mohammed3em/BCRABL-Generative-AI). The release documents the treatment of acyclic molecules as a single scaffold class and preserves the exact train, validation, and independent-test partitions used in the study. ChEMBL- and BindingDB-derived records are redistributed with source attribution under the applicable upstream database terms. Large intermediate working files, most fitted-model binaries, final REINVENT model weights, raw docking project files, and molecular-dynamics trajectories are not included.
